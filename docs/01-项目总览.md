# 01 - 项目总览

核对日期：2026-10-14。React 19、Vite、TypeScript、Tailwind CSS 网页用户端；具体依赖版本见 `package.json`。

当前四个主入口：AI语音、场景对话、电影模仿、我的。入口及页面装配以 `src/App.tsx` 为准。

网页通过 `src/lib/api.ts` 对接后端；电影配音工程通过 `src/lib/dubbing-project.ts` 使用 IndexedDB 保存最近一个作品。不能将项目描述为无后端或全部数据只存 localStorage。

电影模仿页已接入本机识别与云端识别客户端、逐句录音、预览和浏览器恢复；生产云服务仍需真实配置与验收。完整网页 MP4 导出不在首次上线范围，不能以媒体处理代码存在认定已交付。
