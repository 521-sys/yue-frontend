## 一、项目简介

**yue-frontend**（包名 `figma-make-app`）是一款基于 React 19 + Vite 8 + TypeScript 5.7 + Tailwind CSS v4 构建的**粤语学习 Web 应用**。项目以「离线优先、无后端」为核心理念，所有学习数据通过浏览器 `localStorage` 持久化，开箱即用，无需任何服务端接口。

应用采用底部 5 Tab 移动端布局（最大宽度 `430px`），提供从「记词 → 背词 → 跟读 → 测试 → 查词」的完整学习闭环，并辅以社区排行榜、商城激励、个人成就等游戏化机制，帮助学习者持续保持学习动力。

**核心定位**（摘自 `.figma/make/site.json`）：

> This web application offers an interactive platform for learning Cantonese, featuring modules for listening and memorizing vocabulary, tailored for language learners.

### 1.1 项目核心特征

| 特征 | 说明 |
| --- | --- |
| 应用形态 | 单页应用（SPA），移动端优先，最大宽度 430px |
| 数据存储 | 全部基于 `localStorage`，键名 `yueLearnReactV1`，无后端、无云端 |
| 发音方案 | 208 条预生成离线真人粤语音频（微软晓佳 `zh-HK-HiuGaaiNeural`）+ 浏览器 Web Speech API 兜底 |
| 翻译能力 | 内置普通话↔粤语词典，贪心最长匹配算法做整句翻译 |
| 词表规模 | 9 大分类、71 个核心词条，含粤拼、释义、例句、例句翻译 |
| 状态管理 | React 18+ 原生 `useSyncExternalStore` + 自实现发布订阅 |
| 路由方案 | 无第三方路由库，使用 `useState` 切换底部 Tab |
| 构建工具 | Vite 8（dev / build / preview），集成 Figma Make 自定义插件链 |

### 1.2 项目范围与开发版本约定

**本项目（`yue-frontend` / figma-make-app，React + Vite + Tailwind v4 版本）为唯一开发与维护对象。**

同工作目录下的 `cantonese-app`（单页 HTML 版）与 `cantonese-miniprogram`（微信小程序版）不在本项目开发范围内，仅作历史实现与数据来源参考。后续所有功能迭代、文档更新、测试编写均以 `yue-frontend` 为作用域。

### 2.1 关键技术选型说明

- **React 19**：使用最新的 `useSyncExternalStore` Hook 实现外部 store 订阅，无需引入 Redux / Zustand 等状态库。
- **Tailwind CSS v4**：通过 `@import 'tailwindcss'` 接入，配合 `@theme inline` 在 `src/index.css` 中定义主题变量，**不需要 `tailwind.config.js` 与 PostCSS 配置文件**。
- **Vite 8**：内置 ESBuild / Rollup，dev 默认端口 `8443`（由 `process.env.PORT` 控制），`host: 0.0.0.0` 便于局域网联调。

## 三、核心功能模块

应用由 5 个底部 Tab 页面构成，全部在 `src/App.tsx` 中通过 `useState` + `switch` 调度：

```ts
// src/App.tsx 节选
const tabs = [
  { id: "home",     label: "记粤语", icon: BookOpen },
  { id: "study",    label: "背粤语", icon: GraduationCap },
  { id: "together", label: "一起学", icon: Users },
  { id: "shop",     label: "商城",   icon: ShoppingBag },
  { id: "profile",  label: "我",     icon: User },
];
```

### 3.1 记粤语（HomeScreen）

## 五、运行方式

### 5.1 npm scripts（`package.json`）

| 命令 | 实际执行 | 用途 |
| --- | --- | --- |
| `npm run dev` | `vite --host 0.0.0.0` | 启动开发服务器，默认端口 8443（由 `process.env.PORT` 控制），HMR 热更新 |
| `npm run build` | `vite build` | 生产构建，输出到 `dist/`，启用压缩、关闭 sourcemap |
| `npm run preview` | `vite preview` | 本地预览构建产物，默认端口 8443 |
| `npm run format` | `oxfmt` | 代码格式化 |

### 5.2 开发流程示例

```bash
# 1. 安装依赖（项目自带 pnpm-lock.yaml，推荐 pnpm）
pnpm install

# 2. 启动开发服务器
pnpm dev
#    → Local:   http://localhost:8443/
#    → Network: http://<局域网 IP>:8443/

# 3. 生产构建
pnpm build
#    → dist/index.html
#    → dist/assets/index-*.js
#    → dist/assets/index-*.css
#    → dist/audio/*.mp3（来自 public/audio）
#    → dist/robots.txt（site.json robots.index=false 时生成）

# 4. 预览构建产物
pnpm preview
```

### 5.3 Figma Make 内置开发

按 `AGENTS.md` 说明，在 Figma Make 环境内 Vite 开发服务器**已自动启动**在 `$PORT`（默认 8443），无需手动执行 `pnpm dev`，预览面板会自动加载应用并支持热重载。

### 5.4 关键环境变量

| 变量 | 默认值 | 作用 |
| --- | --- | --- |
| `PORT` | `8443` | Vite dev / preview 端口（`strictPort: true`） |
| `FIGMA_PUBLIC_URL` | 无 | 设置后作为 Vite `base`，用于子路径部署 |
| `mode` | `production` | `--mode development` 时启用 inline sourcemap，关闭压缩 |

## 七、项目特色

1. **纯前端、零后端**：所有数据存 `localStorage`，无登录、无账号、无云端同步需求，部署即用，可托管在任意静态站点（GitHub Pages / Vercel / Figma Make）。

2. **离线粤语音频包**：208 条由微软晓佳 `zh-HK-HiuGaaiNeural` 预生成的真人发音（71 词 + 71 例句 + 5 段对话 + 翻译词典条目），未收录文本自动回退浏览器 TTS。

3. **双向粤语词典 + 贪心最长匹配**：`dictionary.ts` 提供 `translate`（普通话→粤语整句分段）与 `reverseLookup`（粤语→普通话），词典按普通话长度降序排列，做贪心最长匹配，未命中字符原样保留。

4. **AI 发音评分**：`HomeSheets.tsx` 的跟读训练使用 `MediaRecorder` 录音 + `webkitSpeechRecognition`（`lang: zh-HK`）识别 + LCS 最长公共子序列相似度算法打分。

5. **React 19 原生状态管理**：`useSyncExternalStore` + 自实现发布订阅，零第三方状态库，store 单例 + `listeners: Set`，HMR 安全。

6. **学习闭环 + 游戏化**：记词（斩词 quiz）→ 背词（翻卡跟读）→ 跟读（AI 评分）→ 检测 → 查词，配合铜板、连续打卡、成就徽章（8 个）、排行榜，形成完整激励回路。

7. **移动端沉浸式设计**：430px 最大宽度，渐变头（`linear-gradient(160deg, #1a3fbf, #2B5CE6, #4a7cf7)`），底部 Tab 切换时图标 / 文字色变 (`#2B5CE6`)，全局隐藏滚动条，自定义 `sheetUp` / `fadeIn` 动画。

8. **Figma Make 工程化集成**：`vite.config.ts` 内置 4 个自定义插件——`figmaSiteConfiguration`（注入 site.json 配置）、`figmaErrorOverlayReplay`（错误覆盖层重放）、`figmaReactRefreshBoundaryFallback`（HMR 边界兜底）、`figmaMakeKitPlugin`（dev-only 的组件 stories 网格）。
