# 08 - UI 设计规范

> 文档版本：v1.0  
> 适用项目：yue-frontend / figma-make-app  
> 依据：`src/index.css`（@theme 令牌）+ `src/components/Sheet.tsx` + 各 Screen 实际样式  
> 目标：统一视觉语言，新增组件时遵循本规范以保持一致性

---

## 一、设计基调

| 维度 | 取值 | 说明 |
| --- | --- | --- |
| 应用形态 | 移动端单页，最大宽度 `430px`，居中 | `max-w-[430px] mx-auto` |
| 主色 | 蓝色 `#2B5CE6` | 信任、学习、专注 |
| 强调色 | 橙金 `#F5A623` | 铜板、激励、点缀 |
| 背景 | 浅蓝灰 `#F0F4FF` | 柔和、护眼 |
| 圆角语言 | 大圆角为主（`rounded-2xl` / `rounded-3xl` / `rounded-full`） | 移动端友好 |
| 字体 | Noto Sans SC（正文）/ Noto Serif SC（标题强调） | 中文字体兜底 PingFang SC、Microsoft YaHei |
| 交互反馈 | `active:scale-95` / `active:scale-90` + `transition-transform` | 按压缩放，触感反馈 |

## 二、主题色板（Design Tokens）

来源：[src/index.css](file:///c:/Users/liu123/WorkBuddy/2026-09-01-20-12-50/yue-frontend/src/index.css) 的 `@theme inline` 块。Tailwind v4 通过这些令牌生成 `bg-primary`、`text-accent` 等工具类。

| 令牌 | 值 | 语义 | 用法示例 |
| --- | --- | --- | --- |
| `--color-primary` | `#2B5CE6` | 主色 | Tab 高亮、主按钮、链接 |
| `--color-primary-light` | `#4A7CF7` | 主色浅 | 渐变终止色、次级强调 |
| `--color-accent` | `#F5A623` | 强调色 | 铜板图标、激励徽章 |
| `--color-accent-dark` | `#E8950F` | 强调色深 | 渐变终止色 |
| `--color-bg` | `#F0F4FF` | 页面背景 | 根容器底色 |
| `--color-card` | `#FFFFFF` | 卡片背景 | 卡片、抽屉内白底 |
| `--color-text` | `#1a1a2e` | 主文本 | 标题、正文 |
| `--color-muted` | `#7a8499` | 次要文本 | 说明、占位 |
| `--color-success` | `#22c55e` | 成功 | 已掌握、已拥有 |
| `--color-danger` | `#ef4444` | 危险/错误 | 选错、删除 |

### 2.1 直接硬编码的高频色

部分组件直接用了 16 进制（未走令牌），新增类似场景保持一致：

| 色值 | 用途 |
| --- | --- |
| `#EEF3FF` | SoundButton 底色、空状态图标底 |
| `#1a1a2e/92` | Toast 半透明黑底 |
| `#dce8ff` | 商品图卡渐变终止 |

## 三、字体规范

### 3.1 字体栈

```css
/* src/index.css */
body {
  font-family: 'Noto Sans SC', 'PingFang SC', 'Microsoft YaHei', sans-serif;
}
```

粤拼等罗马字使用等宽字体（`font-mono`，对应 Consolas/Menlo），见 `WordRow` 的 `w.jyut`。

### 3.2 字号层级

| 层级 | Tailwind | 像素 | 用途 |
| --- | --- | --- | --- |
| 巨大 | `text-5xl` | 48px | 商品 emoji |
| 大标题 | `text-lg` / `text-xl` | 18-20px | 页面标题、Sheet 标题 |
| 词主字 | `text-[34px]` | 34px | 今日一词的粤字 |
| 正文 | `text-sm` / `text-base` | 14-16px | 列表、说明 |
| 辅助 | `text-xs` | 12px | 标签、时间 |
| 微注 | `text-[10px]` / `text-[11px]` | 10-11px | 角标、价格单位 |

### 3.3 字重

| Tailwind | 字重 | 用途 |
| --- | --- | --- |
| `font-black` | 900 | 价格、Hero 数字 |
| `font-bold` | 700 | 标题、Tab 高亮 |
| `font-medium` | 500 | Tab 文字、按钮 |
| `font-normal` | 400 | 正文 |

## 四、间距与布局

| 场景 | 间距 |
| --- | --- |
| 页面水平内边距 | `px-4`（16px） |
| 卡片内边距 | `p-3` ~ `p-4`（12-16px） |
| 列表项间距 | `gap-2` ~ `gap-3`（8-12px） |
| 区块垂直间距 | `mb-4` / `mt-4`（16px） |
| 底部安全区 | Sheet 内容 `pb-8`（32px） |

布局以 Flexbox 为主：`flex flex-col h-full` 撑满，内容区 `flex-1 overflow-y-auto` 可滚动。

## 五、组件视觉规范

### 5.1 底部抽屉 Sheet

来源：[Sheet.tsx](file:///c:/Users/liu123/WorkBuddy/2026-09-01-20-12-50/yue-frontend/src/components/Sheet.tsx)

```
全屏遮罩 bg-black/40（点击关闭）
└─ 抽屉容器 max-w-[430px] bg-[#f0f4ff] rounded-t-3xl max-h-[88vh] animate-sheet-up
   ├─ 标题栏 px-4 pt-4 pb-3（标题 font-bold text-lg + 关闭按钮 rounded-full bg-gray-100）
   └─ 内容区 flex-1 overflow-y-auto px-4 pb-8
```

- 动画：`animate-sheet-up`（`@keyframes sheetUp` 0.25s ease，从 translateY(100%) 到 0）。
- 新增抽屉一律复用 `<Sheet>` 容器，保持一致的圆角、遮罩、动画。

### 5.2 按钮

| 类型 | 样式 |
| --- | --- |
| 主按钮 | `bg-[#2B5CE6] text-white` + `active:scale-95` |
| 次按钮 | `bg-[#EEF3FF] text-[#2B5CE6]` |
| 禁用/不足 | `bg-gray-100 text-gray-400` |
| 成功态 | `bg-green-100 text-green-600` |
| 圆形图标按钮 | `w-8 h-8 rounded-full bg-gray-100` + `active:scale-95` |

所有按钮统一加 `transition-transform`，按压时 `active:scale-95`（圆形图标按钮用 `active:scale-90`）。

### 5.3 卡片

- 通用卡片：`bg-white rounded-2xl shadow-sm shadow-blue-50`。
- 商品图卡：`bg-gradient-to-br from-[#EEF3FF] to-[#dce8ff]`。
- 渐变 Hero（如商城顶部）：`linear-gradient(160deg, #1a3fbf 0%, #2B5CE6 50%, #4a7cf7 100%)`。

### 5.4 头像/词首字块

```tsx
<div className="w-10 h-10 rounded-lg bg-gradient-to-br from-[#2B5CE6] to-[#4a7cf7] flex items-center justify-center">
  <span className="text-white font-bold text-lg">{w.yue}</span>
</div>
```

### 5.5 发音按钮 SoundButton

```tsx
<button className="flex items-center justify-center rounded-full bg-[#EEF3FF] active:scale-90 transition-transform">
  <Volume2 className="text-[#2B5CE6]" />
</button>
```

### 5.6 底部 Tab 栏

来源：[App.tsx](file:///c:/Users/liu123/WorkBuddy/2026-09-01-20-12-50/yue-frontend/src/App.tsx)

- 容器：`bg-white border-t border-gray-100 shadow-[0_-2px_12px_rgba(0,0,0,0.06)]`。
- 选中态：图标底块 `bg-[#2B5CE6]` 圆角，图标缩小至 18px、白色；文字 `text-[#2B5CE6]`。
- 未选中：图标 22px、`text-gray-400`；文字 `text-gray-400`。
- 文字统一 `text-[11px] font-medium`。

## 六、动效

| 名称 | 关键帧 | 时长 | 用途 |
| --- | --- | --- | --- |
| `animate-sheet-up` | `translateY(100%) → 0` | 0.25s ease | 抽屉弹出 |
| `animate-fade-in` | `opacity 0 → 1` | 0.2s ease | Toast、遮罩 |

定义在 `src/index.css`。新增动效优先复用这两个；如需新动画，在 `index.css` 用 `@keyframes` 定义并加 `.animate-xxx` 类。

## 七、图标规范

统一使用 `lucide-react`，**不混用其他图标库**。

| 场景 | 推荐图标 |
| --- | --- |
| 发音 | `Volume2` |
| 关闭 | `X` |
| 删除 | `Trash2` |
| 翻页 | `ChevronLeft` / `ChevronRight` |
| 学习 | `BookOpen` / `GraduationCap` / `BookMarked` |
| 社交 | `Users` / `Trophy` / `Star` |
| 商城 | `ShoppingBag` / `Coins` |
| 个人 | `User` / `Settings` |

图标 `size` 按层级：列表 16px、按钮 18-20px、装饰 28-32px。`strokeWidth`：激活 2.5、常态 1.8。

## 八、空状态规范

参考 `StuckList` 的空状态：

```
居中容器 py-16 gap-3
├─ 图标底块 w-16 h-16 rounded-2xl bg-[#EEF3FF]
│  └─ 图标 text-[#2B5CE6] size=28
├─ 主文案 text-gray-500 text-sm
└─ 副文案 text-gray-400 text-xs
```

所有列表为空时遵循此结构，保持一致的"温柔提示"基调。
