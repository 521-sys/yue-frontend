# 05 - 接口文档

> 适用范围：`yue-frontend` 粤语学习 Web 应用
> 技术栈：React 19 + Vite 8 + TypeScript + Tailwind v4
> 文档目的：说明本项目所有对外暴露的模块接口、组件 Props 与持久化契约

---

## 概述

本项目是**纯前端无后端应用**，不存在任何 HTTP/REST API、GraphQL 或 WebSocket 接口。所有"接口"分为三类：

- **(A) 内部模块接口**：以 TypeScript 函数 / 常量形式导出，供其他模块导入调用。
- **(B) 组件接口**：React 组件的 Props 定义，供页面/父组件渲染。
- **(C) localStorage 契约**：与浏览器本地存储的读写约定。

### A.1.5 `markLearned`

```ts
export function markLearned(id: string): void;
```

| 项 | 描述 |
| --- | --- |
| 参数 | `id: string`：词 id（如 `"w1"`，对应 `Word.id`） |
| 返回值 | 无 |
| 副作用 | 1. `bumpActivity`：今日 `activity[d]` +1；<br>2. `touchStreak`：跨日时更新 `streak` 与 `lastDay`；<br>3. 若 `learned` 不含该 id，则追加；<br>4. `todayLearned` 跨日重置为 1 或同日 +1；<br>5. 写入 localStorage 并通知订阅者 |
| 调用场景 | 「记粤语」答题正确时调用 |

```ts
// 实现摘要
export function markLearned(id: string) {
  const s = bumpActivity(touchStreak(state));
  const d = today();
  const learned = s.learned.includes(id) ? s.learned : [...s.learned, id];
  save({
    ...s,
    learned,
    todayLearned: s.todayLearnedDate === d ? s.todayLearned + 1 : 1,
    todayLearnedDate: d,
  });
}
```

## A.2 `src/data/dictionary.ts`

普通话 ↔ 粤语转换词典与翻译引擎。

### A.2.1 接口总览

| 导出名 | 类型 | 用途 |
| --- | --- | --- |
| `WordMapEntry` | type | 词典三元组类型 `[普通话, 粤语, 粤拼]` |
| `Seg` | interface | 翻译分段结果 |
| `ReverseHit` | interface | 反向查询结果 |
| `WORDMAP` | const | 词典数据（按普通话长度降序） |
| `translate` | function | 普通话 → 粤语分段 |
| `reverseLookup` | function | 粤语 → 普通话释义 |
| `hasKnown` | function | 转换结果是否命中词典 |

### A.2.2 `translate`

```ts
export function translate(text: string): Seg[];
```

| 项 | 描述 |
| --- | --- |
| 参数 | `text: string`：普通话原文 |
| 返回值 | `Seg[]`：分段结果数组。命中词典的段 `known=true`；未命中的单字段 `known=false`、`jyut=""` |
| 副作用 | 无（纯函数） |
| 调用场景 | 「记粤语」输入普通话查粤语翻译 |

```ts
export interface Seg {
  man: string;
  yue: string;
  jyut: string;
  known: boolean;
}
```

> 算法：**贪心最长前缀匹配**。依赖 `WORDMAP` 按普通话长度降序排列，从当前位置 `i` 起，按 `WORDMAP` 顺序找第一个 `text.startsWith(WORDMAP[k][0], i)` 命中的词条；命中则整段切分，未命中则单字切分。

### A.2.3 `reverseLookup`

```ts
export function reverseLookup(yueText: string): ReverseHit[];
```

| 项 | 描述 |
| --- | --- |
| 参数 | `yueText: string`：粤语文本 |
| 返回值 | `ReverseHit[]`：先返回**精确匹配**（`yue === yueText`）的条目，再返回**模糊匹配**（`yue.includes(yueText)` 且 `yueText.length >= 1`）的条目 |
| 副作用 | 无 |
| 调用场景 | 「记粤语」输入粤语查普通话释义 |

```ts
export interface ReverseHit {
  yue: string;
  man: string;
  jyut: string;
}
```

### A.2.4 `hasKnown`

```ts
export function hasKnown(segs: Seg[]): boolean;
```

| 项 | 描述 |
| --- | --- |
| 参数 | `segs: Seg[]`：`translate` 的返回值 |
| 返回值 | `boolean`：是否至少有一个 `known=true` 的段 |
| 副作用 | 无 |
| 调用场景 | 判断翻译结果是否有效（用于禁用「斩」按钮等） |

### A.2.5 `WORDMAP`

```ts
export const WORDMAP: WordMapEntry[];
export type WordMapEntry = [string, string, string];
```

| 项 | 描述 |
| --- | --- |
| 类型 | `WordMapEntry[]` |
| 排序 | 按普通话字段长度**降序**排列 |
| 用途 | `translate` 与 `reverseLookup` 的数据源 |
| 注意 | 修改时必须维持降序，否则 `translate` 最长匹配会失效 |

### A.4.2 `speak`

```ts
export function speak(text: string, rate?: number): boolean;
```

| 项 | 描述 |
| --- | --- |
| 参数 | `text: string`：要朗读的文本（如 `Word.yue`、`Word.example`）；<br>`rate?: number`：播放速率，默认 `1` |
| 返回值 | `boolean`：是否命中离线音频（`true` 命中并播放；`false` 已回退到浏览器 TTS） |
| 副作用 | 命中离线：创建 `<audio>` 元素播放对应 MP3；未命中：调用 `speechSynthesis.speak()`。播放前会停止任何进行中的播放 |
| 调用场景 | 「发音跟读」「背粤语」点击发音按钮、答题正确朗读 |

```ts
// 实现摘要
export function speak(text: string, rate = 1): boolean {
  const src = AUDIO_MANIFEST[text];
  if (src) {
    playFile(src, rate);   // 优先离线
    return true;
  }
  speakTTS(text, rate);     // 兜底 TTS
  return false;
}
```

# (C) localStorage 契约

本项目与浏览器的持久化约定如下。

## C.1 键名契约

| 项 | 值 |
| --- | --- |
| 键名 | `yueLearnReactV1` |
| 来源 | `src/lib/store.ts` 中的 `const KEY = "yueLearnReactV1"` |
| 命名约定 | `yue` + `Learn` + `React` + `V1`（业务/技术栈/版本） |
| 唯一性 | 应用全量共享单键，所有学习状态集中存储 |

## C.2 值格式契约

| 项 | 描述 |
| --- | --- |
| 序列化格式 | JSON 字符串（`JSON.stringify`） |
| 反序列化 | `JSON.parse`，异常时回退到 `DEFAULT` |
| 顶层结构 | `LearningState` 对象 |
| 字段合并策略 | 读取时 `{ ...DEFAULT, ...parsed }`：旧数据缺失的字段以默认值补全 |
| 字符编码 | UTF-8 |

值结构示例：

```json
{
  "learned": ["w1", "w3", "w9"],
  "stuck": ["w5"],
  "reviewed": ["w1", "w2"],
  "streak": 4,
  "lastDay": "2026-09-01",
  "todayLearned": 7,
  "todayLearnedDate": "2026-09-02",
  "todayReviewed": 3,
  "todayReviewedDate": "2026-09-02",
  "dailyGoal": 10,
  "activity": {
    "2026-08-27": 8,
    "2026-08-28": 12,
    "2026-08-29": 10,
    "2026-08-30": 9,
    "2026-08-31": 11,
    "2026-09-01": 13,
    "2026-09-02": 10
  },
  "coins": 86,
  "owned": ["粤语俚语大全"]
}
```

## C.3 读写时机契约

| 时机 | 触发动作 | 调用方 |
| --- | --- | --- |
| **应用启动** | `localStorage.getItem(KEY)` + `JSON.parse` + 字段合并 | `store.ts` 模块初始化时调用 `load()` 一次 |
| **状态变更** | `localStorage.setItem(KEY, JSON.stringify(next))` | 任何 mutation 函数内部调用 `save()` 时 |
| **跨日学习** | `touchStreak` 比对 `lastDay` 与今天/昨天；写入新 `streak` 与 `lastDay` | `markLearned` / `markStuck` / `markReviewed` 内部 |
| **每日计数** | `todayLearnedDate` / `todayReviewedDate` 与今天比对：同日累加，跨日重置为 1 | `markLearned` / `markReviewed` 内部 |
| **活动日历** | `bumpActivity` 将今日 `activity[d]` 自增 1 | `markLearned` / `markStuck` / `markReviewed` 内部 |
| **购买商品** | 校验 `owned` 不含 + `coins` 充足 → 扣减 `coins` + 追加 `owned` | `buyItem` |
| **重置** | 整体写回 `DEFAULT` | `resetAll` |
| **读取失败** | `JSON.parse` 抛错或返回 `null` → 回退 `{ ...DEFAULT }` | `load()` 的 `try/catch` |
| **写入失败** | `localStorage.setItem` 抛错（配额超限/隐私模式）→ 静默忽略，内存状态已更新 | `save()` 的 `try/catch` |

## C.4 不变式契约

调用方需遵守以下不变式，否则行为未定义：

| 不变式 | 描述 |
| --- | --- |
| 词 id 稳定性 | `learned`/`stuck`/`reviewed` 中的字符串必须为 `Word.id`（`w1`…`w71`）。词表顺序不可调整，否则历史数据失配 |
| 商品名一致性 | `owned` 中的字符串必须为 `ShopScreen.items[i].name`；改名会导致「已拥有」判定失效 |
| 单线程访问 | 所有 mutation 同步执行，禁止在 mutation 内部再次触发 mutation（避免循环 save） |
| 不可变快照 | `getState` 返回的对象不可在调用方修改；如需修改必须通过 mutation 函数 |
| 日期格式 | `lastDay` / `todayLearnedDate` / `todayReviewedDate` / `activity` 的键均为 `YYYY-MM-DD`（UTC，由 `new Date().toISOString().slice(0,10)` 生成） |

## C.5 订阅与渲染契约

```ts
// React 组件订阅
const s = useLearning();
// s 是不可变快照，每次 save 后会自动触发重渲染
```

```ts
// 非 React 上下文读取
import { getState } from "../lib/store";
const coins = getState().coins;
```

> ⚠️ 在事件回调或 `setTimeout` 中读取状态应使用 `getState()`，而不是缓存 `useLearning()` 的返回值（后者可能是过期快照）。
