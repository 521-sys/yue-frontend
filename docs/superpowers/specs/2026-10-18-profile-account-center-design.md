# “我的”账号中心与收藏页设计

日期：2026-10-18
状态：已完成对话与视觉方案确认，等待书面审阅

## 目标

重新设计网页端“我的”板块并最终部署到既有生产服务器。新页面应让未登录用户直接完成密码登录或快速注册，让已登录用户查看真实同步状态、编辑资料和管理场景收藏。旧版“每日学习目标”“每日背词”“基础设置”和“重置学习进度”全部从界面删除。

## 已确认范围

### 未登录状态

- 采用已确认的 C“极简登录”方向。
- “我的”页面直接展示登录内容，不再先显示用户卡片并弹出旧登录 Sheet。
- 保留手机号或用户名加密码的登录方式、密码显隐和回车提交。
- 保留独立的快速注册流程及返回登录入口。
- 生产暂不显示短信登录。短信客户端代码保留，通过构建配置关闭入口；待腾讯短信应用、签名、模板、专用密钥、数据库迁移和单条验收全部完成后另行开放。

### 已登录状态

- 采用已确认的 C3“功能列表”方向。
- 顶部资料卡显示头像、昵称、账号、云端同步摘要和编辑资料按钮。
- 列表只保留“云端同步状态”和“我的收藏”。“关于与帮助”不做。
- 页面底部提供明确且独立的退出登录按钮。
- 不展示每日学习目标、每日背词、基础设置或重置学习进度。

### 我的收藏

- 第一阶段只支持后端已具备的场景对话收藏，不扩展 AI 语音或电影模仿收藏。
- 采用已确认的 F2“极简列表”。每项显示场景图标、标题、地点和句数。
- 支持加载中、失败重试、无收藏引导和取消收藏。
- 点击整行后切换到主导航“场景对话”，并直接打开该官方场景的最新练习详情。
- 心形按钮只执行取消收藏，不触发场景跳转；失败时保留列表项并显示错误。

## 架构与组件

### 顶层导航

`App` 继续拥有四个主 Tab，但新增一个待打开官方场景的导航状态。`ProfileScreen` 通过回调请求打开收藏场景；`App` 切换到场景 Tab 并把场景 ID 传给 `SceneDialogueScreen`。场景页负责从公共接口重新读取该场景并显示详情，避免在收藏页复制练习界面。

### 账号中心

`ProfileScreen` 管理“账号主页 / 收藏列表”两个子视图：

- 未登录时渲染重新排版后的 `AuthFlow`。
- 已登录时读取个人资料并渲染 C3 资料卡及功能列表。
- 收藏入口打开独立的 `FavoritesView`，返回后仍停留在“我的”主 Tab。
- 编辑资料沿用现有接口和头像选择 Sheet，但视觉样式与新页面统一。

### 短信入口开关

登录组件读取显式构建变量，例如 `VITE_SMS_LOGIN_ENABLED`。只有值为 `true` 时才渲染短信 Tab；缺省和本次生产构建均为关闭。短信 API 与状态函数不删除，以便后续短信上线任务复用。

### 收藏数据

前端 API 层新增已登录请求：

- `GET /api/scenes/favorites`：读取当前用户可见的收藏场景。
- `DELETE /api/scenes/{id}/favorite`：取消收藏。

返回值映射到现有 `Dialogue` 结构，沿用官方场景 `official:<id>` 标识。取消成功后从当前列表移除；若列表变空则切换为空状态。

### 同步状态

学习状态存储增加独立的可订阅同步状态，不把展示逻辑塞进页面：

- `syncing`：本地变化已排队或正在上传。
- `synced`：登录后云端拉取成功，或最近一次上传成功。
- `error`：云端拉取或上传失败。
- 未登录时不展示同步行，并在退出时清空状态。

现有 1.5 秒防抖上传保持不变。状态只反映真实请求结果，不显示伪造时间；本次不新增手动同步按钮。

## 错误与边界处理

- 个人资料读取失败时仍显示账号名称和默认头像，页面保持可退出。
- 收藏接口返回 401 时沿用现有认证失效逻辑清除登录态并返回登录界面。
- 收藏加载失败显示原位错误和重试按钮，不显示旧数据为成功结果。
- 取消收藏失败时不先永久移除项目，向用户显示可恢复错误。
- 收藏场景已下架或删除时，场景页显示现有“场景读取失败”并回到场景列表，不恢复内置旧数据。
- 同步失败只改变同步状态，不阻塞本地学习；重新登录后重新拉取云端状态。
- 短信开关关闭时，页面和无障碍树中都不存在短信 Tab。

## 测试策略

按测试驱动顺序实施：先添加能因现有行为而失败的测试，再做最小修改。

1. 未登录 C 页面直接显示密码登录和快速注册，隐藏短信、基础设置、每日目标和重置入口。
2. 已登录 C3 页面显示资料、真实同步状态、收藏入口和退出按钮，且所有旧设置不存在。
3. 同步状态覆盖排队、成功、失败和退出清空。
4. 收藏 API 覆盖读取、取消和错误响应。
5. 收藏视图覆盖加载、数据列表、空状态、重试和取消失败。
6. 顶层导航覆盖从收藏项切换到场景 Tab 并打开指定场景。
7. 运行完整前端测试、生产构建和 `git diff --check`。
8. 使用手机尺寸浏览器检查未登录、注册、已登录、资料编辑、收藏列表和场景跳转。

## 部署与回滚

- 在独立工作树和独立功能分支中实现，不纳入原前端目录中尚未提交的语音修改及 `dist.tgz`。
- 构建产物只包含本设计范围和此前已经提交的功能。
- 部署前备份当前 `/var/www/yue`，生成并核对产物 SHA-256。
- 只替换用户端静态文件；本次不迁移数据库、不部署短信后端、不修改短信环境变量、不消耗配音识别额度。
- 上线后验证：首页与静态资源 200、密码登录和注册界面、未登录收藏接口 401、已登录收藏读取/取消、收藏到场景跳转、管理后台、公开场景 API 和官方音频。
- 若静态资源、登录或核心导航门禁失败，立即恢复同一时点网页备份并重新加载 Nginx。

## 不在本次范围

- AI 语音或电影模仿收藏。
- “关于与帮助”页面、客服或在线反馈。
- 删除学习状态中的历史 `dailyGoal` 字段；本次只删除其 UI，保留数据兼容，避免无关迁移。
- 合并或发布原前端目录里未提交的语音功能修改。
