## 一、项目背景与目标

### 1.1 项目背景

粤语（广州话 / 香港粤语）是华南地区及港澳通行的主要汉语方言，使用人口过亿。随着粤港澳大湾区交流日益频繁，大量普通话母语者有碎片化、低门槛学习粤语的需求——希望在通勤、排队等零碎时间，像刷短视频一样随手练几句粤语。

然而市面上的粤语学习产品普遍存在以下痛点：

- **依赖后端账号体系**：强制注册登录、收集隐私，门槛高；
- **发音不地道**：用普通话 TTS 凑数，声调不准；
- **学习路径割裂**：记词、背词、跟读、查词散落在不同产品；
- **缺乏激励机制**：学几天就放弃。

`yue-frontend` 项目即在此背景下诞生——一款**纯前端、零账号、离线优先**的粤语学习 Web 应用，内置真人粤语音频包、双向词典、AI 发音评分与游戏化激励，打开浏览器即可学习。

### 1.2 项目目标

| 目标维度 | 具体目标 |
| --- | --- |
| 学习闭环 | 提供「记 → 背 → 跟读 → 检测 → 查词」一站式学习路径 |
| 离线可用 | 应用本身与音频资源均可离线运行，断网仍可学习 |
| 零门槛 | 打开网页即用，无需注册登录、无需安装 App |
| 数据持久 | 学习进度、连续打卡、铜板、已购商品全部本地保存 |
| 发音地道 | 208 条真人粤语发音（微软晓佳 `zh-HK-HiuGaaiNeural`）覆盖核心词与例句 |
| 激励留存 | 连续打卡、成就徽章、社区排行榜、铜板商城构成游戏化激励 |

### 1.3 项目范围

**开发版本约定**：本项目仅以 `yue-frontend`（figma-make-app，React + Vite 版）为唯一开发与维护对象；同目录下的 `cantonese-app`（单页 HTML 版）与 `cantonese-miniprogram`（微信小程序版）不在开发范围内，仅作历史与数据来源参考。

**包含**：5 个底部 Tab 页面、71 个核心粤语词条、9 大分类、208 条离线音频、普通话↔粤语双向词典、跟读 AI 评分、生词本、成就系统、本地持久化。

**不包含**：用户账号体系、服务端数据同步、社交真实后端（社区帖子为前端 mock）、付费真实交易（铜板仅靠学习打卡获取，不接入支付）、课程内容管理后台。

## 五、数据需求

### 5.1 学习状态（`LearningState`）

存储位置：浏览器 `localStorage`，键名 `yueLearnReactV1`，JSON 序列化。结构定义于 `src/lib/store.ts`：

```ts
export interface LearningState {
  learned: string[];            // 已「记」（斩）的词 id
  stuck: string[];             // 生词本（选错 / 再背一次）
  reviewed: string[];           // 已「背」过的词 id
  streak: number;               // 连续学习天数
  lastDay: string;             // 最后学习日期（YYYY-MM-DD）
  todayLearned: number;        // 今日已记数量
  todayLearnedDate: string;    // 今日已记的日期（用于跨天重置）
  todayReviewed: number;      // 今日已背数量
  todayReviewedDate: string;
  dailyGoal: number;           // 每日目标（词）
  activity: Record<string, number>; // date -> 当天学习动作数
  coins: number;              // 铜板余额（默认 128）
  owned: string[];             // 已购商品名
}
```

### 5.2 词条数据（`Word`）

定义于 `src/data/words.ts`：

```ts
export interface Word {
  id: string;          // 形如 w1、w2，自动生成
  yue: string;         // 粤语词
  jyut: string;        // 粤拼（如 nei5 hou2）
  man: string;         // 普通话释义
  cat: string;         // 分类 id
  example: string;     // 粤语例句
  exampleMan: string;  // 例句普通话翻译
}
```

9 大分类（`CATS`）：问候礼貌、饮食茶记、交通出行、购物讲价、数字金钱、日常用语、时间日期、职场用语、俗语称赞。

### 5.3 词典数据（`WORDMAP`）

定义于 `src/data/dictionary.ts`，每条 `[普通话, 粤语, 粤拼]` 三元组，按普通话长度降序排列做贪心最长匹配。

### 5.4 音频映射（`AUDIO_MANIFEST`）

定义于 `src/data/audio-manifest.ts`，`Record<string, string>` 文本→`/audio/a0XXX.mp3` 路径，共 208 条，覆盖 71 词、71 例句、5 段对话及翻译词典条目。对应 mp3 文件位于 `public/audio/`，构建时复制到 `dist/audio/`。

### 5.5 社区 / 排行榜数据

`TogetherScreen.tsx` 中硬编码 mock 数据（6 名用户、2 条帖子），仅前端展示，不入库、不同步。

## 六、约束条件

| 编号 | 约束 | 说明 |
| --- | --- | --- |
| CON-01 | **无后端** | 项目不实现任何服务端，所有数据本地存储，社区 / 排行榜为前端 mock |
| CON-02 | **无账号** | 不做用户注册登录，无云端同步，数据仅存于当前浏览器 |
| CON-03 | **无支付** | 商城铜板仅靠学习打卡获取，不接入真实支付通道 |
| CON-04 | **移动优先** | 容器宽度锁定 `max-w-[430px] mx-auto`，不为桌面端做单独布局 |
| CON-05 | **React 19 + Vite 8** | 技术栈锁定，不引入 Next.js / Remix 等 SSR 框架 |
| CON-06 | **Tailwind v4** | 不使用 `tailwind.config.js`，主题通过 `@theme inline` 在 `index.css` 定义 |
| CON-07 | **不引入路由库** | 5 个 Tab 通过 `useState` + `switch` 切换，不使用 react-router |
| CON-08 | **不引入状态库** | 使用 React 原生 `useSyncExternalStore` + 自实现发布订阅 |
| CON-09 | **不引入 UI 库** | 全部 UI 自实现，仅依赖 `lucide-react` 图标 |
| CON-10 | **noindex** | `.figma/make/site.json` 配置 `robots.index = false`，默认不被搜索引擎收录 |
