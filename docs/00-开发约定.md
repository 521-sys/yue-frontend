# 00 - 开发约定

> 文档版本：v1.1（v1.0 仅前端；v1.1 扩展后端联动）  
> 适用项目：`yue-frontend`（前端）+ `yue-backend`（后端）  
> 约定生效日期：2026-09-02  
> 性质：**全局前置约定，优先级高于其他文档中的任何冲突表述**

---

## 一、开发版本范围

**本项目以 `yue-frontend`（前端）+ `yue-backend`（后端）为开发与维护对象，二者通过 HTTP API 联动。**

### 1.1 前端

| 项 | 说明 |
| --- | --- |
| 开发对象 | `yue-frontend/`（figma-make-app） |
| 技术基线 | React 19 + Vite 8 + TypeScript 5.7 + Tailwind CSS v4 |
| 运行方式 | `npm run dev`（默认端口 3000）/ `npm run build` / `npm test` |
| 本地持久化 | 浏览器 `localStorage`，键名 `yueLearnReactV1`（离线兜底 + 未登录场景） |

### 1.2 后端

| 项 | 说明 |
| --- | --- |
| 开发对象 | `yue-backend/`（Spring Boot 3.2.5 + MySQL） |
| 技术基线 | Java 21 + Spring Boot 3.2.5 + Spring Security + JPA + jjwt |
| 运行方式 | IDEA 运行 `YueApplication`（端口 8080）；需先建 MySQL 库 `yue` |
| 联动范围 | 用户账号体系（注册/登录/JWT）+ 学习数据云端同步（last-write-wins） |

### 不在开发范围内的同目录项目

| 目录 | 形态 | 处理方式 |
| --- | --- | --- |
| `cantonese-app/` | 单页 HTML 版（单 `index.html`，内联 CSS/JS） | **不在开发范围**，仅作历史实现参考 |
| `cantonese-miniprogram/` | 微信小程序版（`app.json` + 9 页面） | **不在开发范围**，仅作历史实现与数据来源参考 |

> 这两个目录是同一粤语学习产品的早期/其他端实现，**不再进行任何功能迭代、文档更新或测试编写**。如需参考其数据（如词典、词表），可读取，但产物只落到 `yue-frontend/`。

## 二、约定适用范围

本约定适用于以下所有工作：

- ✅ 前端功能开发 → 只改 `yue-frontend/src/`（不重构现有状态机，仅最小侵入接入）
- ✅ 后端功能开发 → 只改 `yue-backend/src/main/`
- ✅ 文档更新 → 只写 `yue-frontend/docs/`
- ✅ 测试编写 → 只写 `yue-frontend/src/__tests__/` 与 `yue-frontend/docs/06-测试文档.md`
- ✅ 前端依赖 → 只改 `yue-frontend/package.json`
- ✅ 后端依赖 → 只改 `yue-backend/pom.xml`
- ✅ 构建配置 → 只改 `yue-frontend/vite.config.ts` / `vitest.config.ts` / `tsconfig.json`
- ❌ 不改 `cantonese-app/` 任何文件
- ❌ 不改 `cantonese-miniprogram/` 任何文件

## 三、技术基线快照

| 维度 | 选型 |
| --- | --- |
| UI 框架 | React 19 + React DOM 19（StrictMode） |
| 构建工具 | Vite 8（含 4 个 Figma Make 自定义插件） |
| 语言 | TypeScript 5.7（strict） |
| 样式 | Tailwind CSS v4（`@tailwindcss/vite` + `@theme` 令牌） |
| 图标 | lucide-react |
| 状态管理 | `useSyncExternalStore` 自实现发布订阅（`src/lib/store.ts`） |
| 路由 | `useState` 切换底部 Tab，无第三方路由库 |
| 持久化 | `localStorage`（JSON 序列化） |
| 语音 | 离线粤语音频（208 条）优先 + Web Speech API 兜底 |
| 测试 | Vitest 4 + @testing-library/react + jsdom |
| 主题色 | `#2B5CE6`（primary）/ `#F5A623`（accent）/ `#F0F4FF`（bg） |

### 3.2 后端技术基线

| 维度 | 选型 |
| --- | --- |
| 语言/运行时 | Java 21 |
| 框架 | Spring Boot 3.2.5 |
| Web | Spring Web（REST） |
| 数据访问 | Spring Data JPA + Hibernate |
| 安全 | Spring Security + JWT（jjwt 0.12.5，BCrypt 密码） |
| 数据库 | MySQL（库名 `yue`，`ddl-auto: update` 自动建表） |
| 构建 | Maven（IDEA 内置即可，本机无需全局 `mvn`） |
