# 00 - 开发约定

核对日期：2026-10-14。本文替代早期存在目录及范围冲突的约定；[原文归档](history/2026-10-14整理前/00-开发约定.md)不再作为当前指令。

- 工作区包含 `yue-frontend`、`yue-backend`、`yue-admin`、`yue-miniprogram` 四个独立仓库；具体修改范围由当前任务决定。
- 前端以 `src/App.tsx`、组件、配置和当前依赖文件为实现依据；先检查 Git 状态并保留已有改动。
- 需求、草案、实现、测试、提交、远端同步和部署分别记录，不能互相替代。
- 文档中的旧目录、旧导航、历史测试数量和旧上线结论需要重新核实。
- `02`—`10` 号参考文档尚未逐项更新，已加标记；其中仍有用的样式、接口、操作说明也应对照代码使用。
- 项目状态见工作区 [统一入口](../../项目现状总结.md)。独立检出前端时，见 [本仓库总览](01-项目总览.md)和实际代码；不要依赖不存在的同级项目路径。
- 功能修改执行对应测试及必要构建；纯文档整理检查链接、差异与文件保留情况，不把历史测试结果当作本次运行。
