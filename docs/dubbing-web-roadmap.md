# 网页版粤语配音实施路线

目标：用户导入有使用权的短视频，获得可校对字幕，逐句配音，最终导出保留背景音、替换原台词的 MP4。自动分离和识别提供初稿，不承诺对任意素材零误差。

2026-10-13 状态更新：本机 large-v3 粤语识别已接入，静音录制修复、前后最多各 1 秒自适应留白与静止准备倒计时已实现；整片配音预览已接入并通过自动化，待真实设备听感验收；网页 MP4 导出仍未接入。完整变更、验证与未提交状态见 [粤语配音开发记录](../../docs/粤语配音开发记录.md)。下述架构和验收关口是完整产品目标，不代表已全部实现。

## 首发范围（2026-10-13 用户确认）

首发保留导入、粤语识别、录音与网页预览，MP4 导出延后到上线后的独立更新。优先补作品保存恢复和生产识别接入；以下成片导出架构为后续路线，不是首发阻塞项。

## 架构决定

- React 网页负责视频预览、字幕时间轴、逐句录音、试听和工程状态。
- 现有 Java 后端负责登录鉴权、项目与任务元数据、上传授权和下载授权；现有 30 秒实时语音识别接口不复用为整片转写接口。
- 独立 Python 媒体 worker 执行 FFmpeg、分轨、粤语 ASR、时间对齐和混音。它以异步任务处理文件，不阻塞网页请求。生产环境需要独立算力和存储，不能直接塞入现有 2 GB Java 容器。
- 用户点击自动处理并确认上传后，视频才会发送至服务端。任务与产物按用户隔离，提供显式删除和到期清理；未完成这些保护前，不对公网开放上传。
- 第一版限定短片段和浏览器可播放的视频格式。字幕、分离音轨和录音均可由用户校对或替换，避免模型失误使项目无法继续。

## 交付顺序

1. 时间轴基础：视频导入、SRT 导入/导出、句级编辑与定位、逐句录音和重录。当前已实现第一版，并可在当前浏览器保存恢复最近一个作品。可另外导入无台词背景音，在播放器播放、暂停和跳转时与视频同步。
2. 工程持久化与试听：保存视频引用/素材、字幕和各句录音；关闭重开可恢复；背景音与选中录音同步试听，加入预卷与延迟校准。
3. 可导出闭环：上传经过明确确认的素材；后端管理异步任务；媒体 worker 用统一时间轴混音、闪避和 MP4 导出。先允许用户提供已处理的背景音。
4. 自动预处理：抽轨、语音/背景分离、粤语转写与句级对齐，生成可编辑初稿；失败时保留手动导入 SRT 和背景音的路径。
5. 产品打磨：导唱/纯背景切换、录音电平、降噪/压缩/响度预设、任务进度和失败重试、真实素材质量评估。

## 验收关口

- 两句以上录音分别出现在对应画面时间，导出后无明显首尾漂移。
- 原片人声不进入导出音轨；分离残留需要可试听并允许替换背景音。
- 自动字幕可逐句改字、改时间、合并/拆分；错误识别不阻止录音和导出。
- 页面刷新或重新登录后项目状态仍可恢复；原视频和录音可由用户删除。
- 处理任务失败、无 GPU、麦克风拒绝、视频格式不支持时给出可执行的提示。

## 当前限制

2026-10-13 已接入可配置腾讯云普通粤语识别：生产构建使用登录后的配音识别 API，开发环境默认本机识别。尚待腾讯账号开通、服务器私密配置、短样片真实识别和上线验证；不能把模拟测试通过当作线上识别可用。开通部署说明见后端 `docs/tencent-asr-setup.md`。

当前已具备仅供本机使用的识别服务及本地模型，但没有公网媒体服务部署或账号云端存储；页面里的逐句录音和独立媒体渲染核心尚未连通。已实现当前浏览器最近一个作品自动保存恢复，换浏览器或清除网站数据后需要重新导入素材，浏览器也不能自动从普通混音音轨中取出无台词背景音。不得把当前版本标为完整成片功能。
