## 一、整体架构概览

本项目是**纯前端单页应用（SPA）**，无后端服务、无 HTTP API，所有数据持久化基于浏览器 `localStorage`。整体采用经典的**三层架构**：表现层 → 业务层 → 数据层，辅以横切关注层（样式 / 配置 / 构建）。

```
┌──────────────────────────────────────────────────────────────┐
│                       浏览器 (Browser)                         │
│  ┌────────────────────────────────────────────────────────┐  │
│  │                    表现层 (Presentation)               │  │
│  │  App.tsx ─ 路由分发 (useState 切换 Tab)                │  │
│  │   ├─ screens/   5 大页面组件                           │  │
│  │   └─ components/ 通用 Sheet + 业务抽屉                  │  │
│  │        ↑ useLearning() hook 订阅状态                   │  │
│  ├────────────────────────────────────────────────────────┤  │
│  │                    业务层 (Business)                   │  │
│  │  lib/store.ts   状态机 + 发布订阅 + 持久化             │  │
│  │  lib/speech.ts  语音服务（离线音频 → TTS 兜底）         │  │
│  │   ↑ 调用                                            │  │
│  ├────────────────────────────────────────────────────────┤  │
│  │                    数据层 (Data)                       │  │
│  │  data/words.ts        词表（71 词 × 9 分类）           │  │
│  │  data/dictionary.ts   普通话↔粤语翻译词典             │  │
│  │  data/audio-manifest.ts 208 条音频映射                 │  │
│  │  localStorage[key=yueLearnReactV1]  学习状态持久化     │  │
│  └────────────────────────────────────────────────────────┘  │
│                                                               │
│  横切：index.css(Tailwind v4 + 主题色) · vite.config.ts · tsconfig.json
└──────────────────────────────────────────────────────────────┘
```

| 维度 | 选型 | 说明 |

## 四、数据流与状态管理

### 4.1 状态管理架构

项目采用**外部 store + `useSyncExternalStore`** 的轻量状态管理方案，未引入 Redux/Zustand 等三方库：

```
┌──────────────┐   subscribe(fn)    ┌──────────────┐
│  React 组件  │ ──────────────────►│  store.ts    │
│ useLearning()│                    │  listeners   │
│              │ ◄──────────────────│   Set<fn>    │
└──────────────┘   listeners.forEach└──────┬───────┘
                                              │ save(next)
                                              ▼
                                       ┌──────────────┐
                                       │ localStorage │
                                       │ yueLearnReactV1│
                                       └──────────────┘
```

- **单一状态源**：模块级 `let state: LearningState`，所有页面共享。
- **发布订阅**：`listeners: Set<() => void>`，`save()` 后遍历通知。
- **React 桥接**：`useLearning()` 通过 `useSyncExternalStore(subscribe, getState, getState)` 实现响应式订阅。
- **持久化**：每次 `save()` 同步写入 `localStorage`（JSON.stringify）。
- **SSR 兜底**：第三个参数 `getServerSnapshot` 同样传 `getState`，保证预渲染不报错。

### 4.2 状态变更流（示例：斩对一个词）

```
用户点击「认识」按钮
      │
      ▼
markLearned(id)                  // store.ts
      │
      ├─ bumpActivity(state)     // 当天 activity 计数 +1
      ├─ touchStreak(state)     // 更新连续学习天数 streak / lastDay
      ├─ learned.push(id)        // 加入已学列表（去重）
      ├─ todayLearned++          // 今日计数 +1（跨日重置）
      └─ save(next)              // 写入 state + localStorage
             │
             └─ listeners.forEach(l => l())  // 通知所有订阅组件重渲染
```

## 六、页面路由机制

项目**未引入 react-router**，采用最简路由：

```tsx
// App.tsx
const [activeTab, setActiveTab] = useState("home");
const renderScreen = () => {
  switch (activeTab) {
    case "home":    return <HomeScreen onNavigate={setActiveTab} />;
    case "study":   return <StudyScreen />;
    case "together":return <TogetherScreen />;
    case "shop":    return <ShopScreen />;
    case "profile": return <ProfileScreen />;
    default:        return <HomeScreen />;
  }
};
```

- **优点**：零依赖、零 URL 副作用、切换即时；适合单页移动端 Tab 场景。
- **局限**：无浏览器前进/后退、无深链分享。后续若需多页面可平滑迁移到 `react-router`。

底部抽屉（Sheet）的路由同样用 `useState<SheetKind>(null)` 在各 Screen 内部派发，无全局状态。

## 七、构建与部署架构

### 7.1 开发

```bash
npm run dev      # vite --host 0.0.0.0，默认端口 8443（可通过 PORT 覆盖）
```

Vite dev server 提供 HMR，`vite.config.ts` 注入了 4 个 Figma Make 专用插件：
- `figmaSiteConfiguration`：注入 site.json 配置（标题/描述/favicon/OG/robots）。
- `figmaErrorOverlayReplay`：构建错误重放，保证新连接客户端也能看到错误。
- `figmaReactRefreshBoundaryFallback`：React Refresh 边界丢失时全量 reload。
- `figmaMakeKitPlugin`：服务于 `/.figma/make/kit.html` 设计稿预览。

### 7.2 生产构建

```bash
npm run build    # vite build → dist/
npm run preview  # vite preview 预览构建产物
```

- 构建产物：`dist/assets/`（含 `index-*.js` + `index-*.css`）、`dist/audio/`（88 条音频，public 静态复制）。
- `base` 可通过 `FIGMA_PUBLIC_URL` 环境变量配置子路径部署。
- 生产构建关闭 sourcemap 与 minify（dev 模式开启 inline sourcemap）。

### 7.3 部署形态

纯静态部署：dist/ 目录可托管于任意静态服务器（Nginx / Vercel / GitHub Pages / CDN）。无服务端运行时，无数据库，无 API 依赖。

## 八、关键设计决策

| 决策 | 方案 | 理由 |
| --- | --- | --- |
| 无后端架构 | 全数据 localStorage | 开箱即用、零运维、隐私友好；适合个人学习工具 |
| 离线语音优先 | 208 条预生成 mp3 + TTS 兜底 | 保证粤语发音质量（微软晓佳 zh-HK），无网络也能用 |
| 翻译算法 | 贪心最长匹配（按普通话长度降序） | 实现简单、确定性、无需分词模型；词典按长度降序保证多字词优先 |
| 状态管理 | useSyncExternalStore 自实现 | React 原生 API，无额外依赖；订阅粒度可控 |
| 路由方案 | useState 切换 Tab | 移动端单页 Tab 场景足够；避免引入路由库的复杂度 |
| 状态持久化 | JSON.stringify 整体存储 | 结构简单、读写一次完成；默认值合并保证向后兼容 |
| 样式方案 | Tailwind v4 + @theme 令牌 | 原子化 CSS、设计令牌集中管理、构建期生成 |
| 词 id 生成 | `w${i+1}` 数组下标 | 简单稳定；但词典顺序变更会导致 id 漂移（见数据库文档） |

## 九、架构约束与风险

1. **localStorage 容量**：单域约 5–10MB，当前词表 + 状态远低于上限，但音频文件不入存储（静态托管）。
2. **id 稳定性**：`Word.id` 由数组下标生成，词表顺序调整会导致已保存的学习记录错位。如需可演进，应改用稳定 hash id。
3. **翻译覆盖率**：词典仅 83 条，未命中字原样保留，长句翻译质量有限；属预期设计（以学习而非翻译为主）。
4. **TTS 兜底质量**：未收录文本回退浏览器 Web Speech API，不同浏览器粤语 voice 覆盖差异较大。
5. **无路由历史**：浏览器后退键无法回到上一 Tab；如需分享/书签需引入路由。

## 十、架构演进建议

- **跨设备同步**：若需多设备数据同步（指同一 figma 版在多设备间同步，非多端开发），可在数据层增加可选的云端 API（store.ts 的 save/load 抽象即可替换）。
- **路由化**：迁移到 `react-router` 以支持深链与历史栈。
- **词表动态化**：词表改为按 id 索引的 Map，避免下标漂移。
- **测试覆盖扩展**：补充 components/ 与 screens/ 的组件交互测试、speech.ts 的 mock 测试。
